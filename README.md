Authentication App (MERN Stack)
This is a full-stack Authentication Application built with the MERN stack that allows users to securely create and manage their accounts.
Features:
User Registration,User Login & Logout ,Profile Management, Update username. Update password.Secure authentication system, 
Protected routes (only authenticated users can access certain features)
Frontend: 
React.js
Redux Toolkit (RTK) for state management
Bootstrap for responsive UI design
Backend:
Node.js
Express.js
MongoDB (Database)
Security:
Passwords are securely hashed using bcrypt, ensuring user credentials are protected.
Authentication logic ensures that users can only access and modify their own data.
Purpose of the Project:
This project demonstrates how to implement a complete authentication system using modern web technologies, 
including secure password handling, state management with Redux Toolkit, and RESTful API integration between frontend and backend.
